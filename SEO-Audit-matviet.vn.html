Critical  Fix within 1 week

  1. Wrong product condition in schema

    Product Microdata contains itemCondition: UsedCondition while items are new. This can make products show as used/refurbished in Google Shopping. Change to https://schema.org/NewCondition.

  2. Homepage HTML is ~483 KB

    Inline product JSON blobs (all_product[id]={...}) plus a full inlined jQuery 3.6.0 bloat every page and hurt LCP. Externalize jQuery to a cached file; move product JSON to an async fetch.

  3. No Product JSON-LD

    Only scattered Microdata exists. Add a self-contained Product + Offer (price, priceCurrency VND, availability, url) + brand + sku block. Without it the site is ineligible for product rich results.

  4. No author credentials on YMYL health content

    Eye-health articles (viễn thị, lão thị, cườm, contact-lens care) are bylined "Admin." Eye health is YMYL; anonymous authorship fails Expertise outright across 400+ articles. Add named optometrist/technician authors with credentials.

High  Fix within 1 month

  1. Index bloat — duplicate collections

    ~150 collections with heavy semantic overlap: mat-meo / gong-mat-meo / kinh-mat-mat-meo (3 URLs for cat-eye), bestseller vs bestsellers, six gender variants, four "nguyen-gia" variants. All self-canonical + index,follow → cannibalization. Consolidate via canonicals/redirects.

  2. Expired campaign collections indexed

    flash-sale-blackfriday-2024, ctkm-ngay-cua-cha-*, deal-dong-gia-*, san-pham-het-hang are live, indexed, with the generic site-wide meta description. noindex or 410/redirect them.

  3. Pagination signals contradict

    ?page=2 correctly canonicals to page 1 but is still index,follow. Set paginated pages to noindex,follow.

  4. Missing AggregateRating in schema

    Haravan review widgets load client-side, so ratings never reach structured data — no star ratings in SERPs. Inject aggregateRating into Product JSON-LD.

  5. No BlogPosting / Article schema

    Blog posts emit only Organization schema; no datePublished, dateModified, author. Blocks AI Overview citation and article rich results.

  6. No LocalBusiness / Optician schema for 31 stores

    Store-locator is JS-rendered with no schema and addresses aren't crawlable. Add Optician schema (address, telephone, openingHours, geo) per location — a major local + AI-citation win.

  7. HSTS is only 7 days

    max-age=604800. Raise to max-age=31536000; includeSubDomains; preload.

  8. Render-blocking JavaScript

    plugin-script.js, api.jquery.js, main.js from cdn.hstatic.net load synchronously. Add defer. Also add <link rel="preload" as="image"> for the LCP hero.

  9. IndexNow not enabled

    Haravan supports it natively; enable so Bing indexes new products in minutes.

  10. JS-only faceted navigation

    Filtered states (?filter_gender=Nu) aren't server-rendered, so high-intent queries ("gọng kính nữ acetate") can't rank. Server-render key facets as crawlable collections.

  11. Off-topic content dilutes topical authority

    31 "Lifestyle" gift-guide articles (Christmas, Tết, teacher gifts) unrelated to eyewear; the 5 most recent posts are all gift guides. Noindex or prune.

  12. Thin clinical service page

    /pages/dat-lich (eye-exam booking) is <200 words. For a YMYL service page, expand to 600–800 words: the 12-step protocol, equipment, who performs exams, FAQ.

Medium  Fix within 3 months

  1. Add BreadcrumbList + WebSite/SearchAction

    Enables breadcrumb rich results and a sitelinks search box for branded "Mắt Việt" queries.

  2. Organization schema url mismatch

    Schema url uses www.matviet.vn but canonical host is non-www matviet.vn. Align so the Knowledge Panel entity consolidates.

  3. Template merge failures

    Article bodies render "Bài viết này của  sẽ…" with the brand variable blank, across many posts. Fix the Liquid variable.

  4. Weak security headers

    Add Referrer-Policy: strict-origin-when-cross-origin and a real CSP (default-src/script-src); current CSP has no source directives.

  5. ALL-CAPS product titles

    GỌNG KÍNH NỮ QINA QJ6115 B23 → sentence case for better CTR.

  6. Thin collection content

    Many shape/style collections are bare product grids. Add 300–500 words of buyer's-guide copy to permanent collections. (kinh-mat-nu is a good model — its comparison tables are AI-citation friendly.)

  7. Remove dev/test pages from sitemap

    /blogs/dev-test, /pages/test*, /pages/test-redirect.

  8. Add medical disclaimers + external citations

    Cite Bộ Y Tế / Bệnh viện Mắt TP.HCM on health articles and add a "consult a doctor" disclaimer.

Low  Quick wins / backlog

  1. Create llms.txt

    A 2-hour, high-ROI file describing the brand for AI agents; almost no Vietnamese e-commerce sites have it.

  2. Explicit AI-bot Allow rules

    Add Allow for GPTBot / ClaudeBot / PerplexityBot (currently only implicitly allowed; Nutch fully blocked).

  3. Template hygiene

    Fix malformed OG image (http:https://…); fix © 2023 → dynamic year; remove obsolete noodp, meta keywords, revisit-after.

  4. Enrich Organization sameAs

    Add YouTube, TikTok, Zalo, Instagram, Facebook — YouTube presence correlates strongly with AI citations.

  5. Wikipedia / Wikidata entity

    None exists; the brand clearly meets notability (1989, 31 stores, EssilorLuxottica). Highest-leverage long-term GEO move.
